အချက်အလက်ကို ပိုမို တိကျသွားအောင် ပြင်ဆင်ပုံဖော်ပေးထားပါတယ်။
"ဟုတ်မှန်အကျိုးရှိ" က အခြေခံ Network Platform / Hub (ဆုံမှတ်) အဖြစ် ဦးဆောင်ပေးပြီး၊ ထိုဆုံမှတ်မှတစ်ဆင့် နယ်ပယ်တူ/ဝါသနာတူသူများ သီးခြားဆုံစည်းကာ လက်တွေ့ Project များ၊ အတွေ့အကြုံ မှတ်တမ်းများကို ဖန်တီးစေသည့် သဘောတရားဖြစ်ပါတယ်။
Vision (အနာဂတ် မျှော်မှန်းချက်)
> "နယ်ပယ်စုံမှ လူများ အလွယ်တကူ ဆုံစည်းချိတ်ဆက်နိုင်ပြီး၊ ထိုမှတစ်ဆင့် ထွက်ပေါ်လာသော လက်တွေ့အသိပညာများကို စတင်လေ့လာသူတိုင်း လွတ်လပ်စွာ သင်ယူနိုင်မည့် ပွင့်လင်းသော ကွန်ရက်အသိုက်အဝန်းကြီး ဖြစ်လာရန်။"
> 
Mission (လက်ရှိ ဆောင်ရွက်မည့် တာဝန်)
> "လူမှုကွန်ရက် ဆုံမှတ်တစ်ခုအဖြစ် ဆောင်ရွက်ပေးလျက် နယ်ပယ်တူ/ဝါသနာတူသူများ ဆုံစည်းမိစေရန် ချိတ်ဆက်ပေးခြင်း၊ ထိုမှတစ်ဆင့် တွေ့ဆုံပွဲများ၊ လက်တွေ့ Project များနှင့် အသိပညာမှတ်တမ်းများကို ဖန်တီး၍ စတင်လေ့လာသူများ အခမဲ့ လေ့လာနိုင်ရန် စနစ်တကျ မျှဝေပေးခြင်းတို့ကို လုပ်ဆောင်လျက်ရှိပါသည်။"
> 
လုပ်ဆောင်ပုံ အဆင့်ဆင့် (Workflow)
 * The Hub (ဆုံမှတ်): ဟုတ်မှန်အကျိုးရှိ က Social Media Group/Platform အဖြစ် လမ်းဖွင့်ပေးထားပြီး နယ်ပယ်စုံမှ လူများကို Network ရရှိရန် စုစည်းပေးခြင်း။
 * Sub-Community / Matchmaking: အဖွဲ့ဝင်များမှ မိမိတို့ နယ်ပယ်တူ၊ ဝါသနာတူသူများနှင့် သီးခြား ချိတ်ဆက်မိသွားခြင်း။
 * Action & Documentation (Meet, Project, Note): နယ်ပယ်တူသူများ စုပေါင်း၍ တွေ့ဆုံပွဲများပြုလုပ်ခြင်း၊ Project များ အတူဖန်တီးခြင်းနှင့် ရရှိလာသည့် အသိပညာများကို စာဖြင့် စနစ်တကျ မှတ်တမ်းတင်ခြင်း။
 * Open Knowledge Base (Free Education): ထိုမှတ်တမ်းများနှင့် အတွေ့အကြုံများကို Newbie/Learner များ အခမဲ့ ဖတ်ရှုလေ့လာနိုင်အောင် Community ထဲတွင် ပြန်လည်မျှဝေပေးခြင်း။
ဒီလို ပုံဖော်ပေးထားတဲ့ Vision နဲ့ Mission က ခင်ဗျား လိုချင်တဲ့ Social Network Hub ပုံစံနဲ့ ကိုက်ညီမှု ရှိရဲ့လားခင်ဗျာ။
